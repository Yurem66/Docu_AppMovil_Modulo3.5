# Historial de Cambios (Changelog)

Todos los cambios notables, actualizaciones y publicaciones del proyecto **AutoElite Motors & Rentals** se registrarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/) y este proyecto se adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-09-25

### Añadido
- **Modelado UML:** Diseño e integración de Diagramas de Casos de Uso y Secuencia para el proyecto móvil.
- **Guía de Instalación:** Especificación de requisitos y procedimiento de ejecución para archivos APK y entornos Android/iOS.
- **Documentación de API:** Especificación de Endpoints REST y cargas útiles en formato JSON para el consumo de servicios.
- **Manual de Usuario:** Guía explicativa para las pantallas principales, navegación por categorías y simulación de métodos de pago.
- **Estructura Docs-as-Code:** Organización modular de la documentación en GitHub con red de enlaces activa en el README principal.
